# Стиль документации для людей

Пиши только по явной просьбе ([`docs.mdc`](../../.cursor/rules/docs.mdc)). Правила агента — [`writing-docs-and-rules.mdc`](../../.cursor/rules/writing-docs-and-rules.mdc).

Краткие README в `core/api/`, `core/client/`, `core/media_api/` — точки входа со ссылками на `.docs/` и корневой README, без копии руководств. Оглавление — только раздел «Документация» в корневом `README.md`. Отдельный `.docs/README.md` не создавай.

| Аудитория | Каталог |
|---|---|
| Люди, онбординг | [`.docs/`](../../.docs/) |
| Точка входа в часть ядра | `core/<часть>/README.md` |
| Развёртывание, ergoms | [`core/deployment/logic.md`](../../core/deployment/logic.md) |
| Агент | `.cursor/rules/*.mdc` |

## Структура

1. Название и назначение — что это и кому нужно.
2. Что уже установлено на компьютере и что ставит `setup-full`.
3. Шаги: одно действие и ожидаемый результат.
4. Как проверить.
5. Типичные ошибки: симптом, причина, что сделать.
6. Ссылки.

Абзацы — для связей между частями. Списки — для шагов и ограничений. Команды только через ergoms. Ссылка лучше копии того, что уже есть в правиле.

Если затронуты онбординг, безопасность, поддержка или вклад, сверь краткие тексты в [`core/.github`](../../core/.github/) ([`github-org-community.mdc`](../../.cursor/rules/github-org-community.mdc)).

## Термины

| Не пиши | Пиши |
|---|---|
| backend, бэкенд, frontend, интерфейс (о Vue) | **сервер**, **клиент** |
| локальная машина, стенд, поднять | локальная разработка, запустить |
| миграции прошли, накатить | миграции **применились**, **применить** |
| setup, deploy, fallback, workaround | настройка, развёртывание, запасной вариант, обходной путь |
| CLI в тексте для людей | справочник команд |

Имена в коде (`CLIENT_HOST`, `core/client/`, API, JWT, Celery, submodule) не переводи. `setup-full` создаёт `.env` и `databases.yaml` из примеров, затем их проверяют. Первичная установка: `setup-full`, затем при неверной БД `ergoms migrate-all`.

Не смешивай «понадобятся Python и ergoms»: Python нужен до настройки, ergoms появляется после неё.
