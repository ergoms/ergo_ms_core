# Запуск системы разработки

**Архитектурные компоненты системы:**

- **CLIENT** — клиентское веб-приложение на базе Vue.js (TCP-порт 8001)
- **API** — серверное приложение на базе Django (TCP-порт 8000)  
- **CELERY WORKER** — обработчик асинхронных фоновых задач
- **CELERY BEAT** — планировщик периодических задач

## Хранение логов

Система осуществляет централизованное логирование в каталоге `logs/`. Структура каталога включает:

- Журналы подсистемы Celery: `celery.log`, `celery_worker.log`, `celery_beat.log`
- Журналы модулей системы: `video_analysis.log`, `porosity_tasks.log` и их ротационные копии
- Диагностические отчёты и трассировки исключений
- Структурированные подкаталоги: `modules/`, `celery/`, `screenshots/`

Централизация журналов в единой точке файловой системы обеспечивает упрощённую диагностику сбоев, анализ производительности и аудит безопасности.

## Управление сервисами

Подробное описание управления сервисами через CLI см. в разделе [Управление сервисами через CLI](cli.md).

> **ℹ️ Особенность архитектуры:** в режиме разработки Django инициализирует два параллельных процесса: основной обрабатывает HTTP-запросы, вспомогательный осуществляет мониторинг изменений исходного кода и выполняет горячую перезагрузку модулей. Данная конфигурация соответствует штатному режиму функционирования.
