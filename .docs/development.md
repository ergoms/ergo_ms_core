# Запуск системы разработки

**Архитектурные компоненты системы:**

- **API** — серверное приложение Django (TCP-порт 8000)
- **CLIENT** — клиентское приложение Vue.js (TCP-порт 8001)
- **MEDIA API** — CDN, файловый сервер (TCP-порт 8003)
- **CELERY WORKER** — обработчик асинхронных задач (из `celery_workers.yaml`)
- **CELERY BEAT** — планировщик периодических задач

## Хранение логов

Система осуществляет централизованное логирование в каталоге `logs/`. Структура каталога включает:

- Журналы подсистемы Celery: `celery.log`, `celery_worker.log`, `celery_beat.log`
- Журналы модулей системы: `video_analysis.log`, `porosity_tasks.log` и их ротационные копии
- Диагностические отчёты и трассировки исключений
- Структурированные подкаталоги: `modules/`, `celery/`, `screenshots/`

Централизация журналов в единой точке файловой системы обеспечивает упрощённую диагностику сбоев, анализ производительности и аудит безопасности.

## Управление сервисами

Подробное описание команд CLI см. в [Управление сервисами через CLI](cli.md).

**Запуск в режиме разработки:**
- Рекомендуемый способ: `Ctrl+Shift+B` (VS Code/Cursor) — запуск всех сервисов
- Или по отдельности: `ergoms dev`, `ergoms start-client`, `ergoms start-worker`, `ergoms start-beat`, `ergoms start-media`
- Для API + Worker + Beat в одном терминале: `ergoms start-all`

> **ℹ️ Особенность:** `ergoms dev` выполняет прогрев кэшей, затем запускает Django с горячей перезагрузкой модулей.
